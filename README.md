# Редакция

Навык для Claude Code: вы кидаете ссылки на новости в одно окно, Claude пишет из них новости в вашем стиле,
вы правите их в «Редакции» (страница в Claude с вашими черновиками) и говорите «публикуй» — дальше скрипт сам
выкладывает пакет в Telegram, MAX, VK, Facebook, Threads, X, YouTube, Дзен и на ваш сайт.

- **Источники** — одно окно для всех ссылок, повторы отсекаются, пометка рядом со ссылкой — задание для Claude.
- **Стиль автора** — стартовый стиль из вашего Telegram-канала, дальше навык учится на ваших правках после каждого пакета;
  у каждого автора «Редакции» — свой.
- **Галочки площадок** — у каждой новости свои: куда выйдет, решаете вы.
- **Экономно** — публикует движок `rk` без модели: токены уходят только на текст и на разбор сбоев.
- **Безопасно** — вход на площадки делаете вы сами в отдельном окне Chrome; токены лежат только у вас
  в `~/.config/redakciya`, навык никуда их не отправляет и не пишет в настройки.

## Установка

В Claude Code:

```
/plugin marketplace add AndreyZhukovRu/redakciya
/plugin install redakciya@redakciya
```

Перезапустите Claude Code (или выполните `/reload-plugins`), чтобы навык загрузился, и скажите Claude:
**«настрой Редакцию»**. Он спросит, куда публиковать, поставит движок, опубликует вашу
«Редакцию» и проведёт по входу на каждую площадку.

Нужно:
- Claude Code на Mac или Windows, вход в claude.ai (на нём живёт «Редакция»);
- Python 3.11+;
- Google Chrome (на Windows подойдёт и встроенный Microsoft Edge);
- ffmpeg — если в новостях бывает видео.

WSL не поддерживается. После настройки открывайте Claude Code в папке `~/Redakciya`. Папка
`~/.config/redakciya` хранит ваши токены и вошедшие сессии площадок — никому её не отправляйте.

Для Telegram через Telethon — ещё `api_id` с my.telegram.org, для Facebook — страница (не личный профиль)
и приложение Meta. Подробности — в [PLATFORMS.md](skills/redakciya/PLATFORMS.md).

## Как пользоваться

1. Кидайте ссылки в «Источники» (или прямо в чат) → «собери новости».
2. Правьте в «Редакции», ставьте галочки площадок, жмите «Готово».
3. «публикуй» → через несколько минут Claude пришлёт, что где вышло.

## Что внутри

- `skills/redakciya/SKILL.md` — как Claude ведёт сбор и выкладку.
- `skills/redakciya/WRITING.md`, `BRIEF_TEMPLATE.md` — правила новости и задание для пишущих агентов.
- `skills/redakciya/PLATFORMS.md` — площадки: что нужно один раз, ограничения, известные грабли.
- `skills/redakciya/editor/editor.html` — «Редакция».
- `skills/redakciya/engine/` — движок `rk` (Python): публикация, проверки, журнал, стиль.
